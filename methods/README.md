# The methods library

Short notes on research methods and statistical technique, consulted when designing work (PLAYBOOK.md, "The methods library"). Each note gives what an idea says, when it applies and when it does not, the questions it prompts, the debates around it, and its full citation. The library is a source of prompts and never a menu: every method is chosen from first principles for the question in hand, and the reviewer is asked, for every item, whether a better method exists, including methods the library does not mention.

## How citations are verified

No citation enters the library unverified. For each one, on the date recorded in the note:

1. The DOI is resolved in Crossref, and the authors, year, title, journal, volume, issue and pages are copied from the record it returns, never from memory.
2. What the note says the work argues is checked against the work itself: the full text where an open copy exists (a working paper or the authors' own version, named in the note), and otherwise the published abstract, in which case the note says so and claims nothing the abstract does not support.
3. Corrections and errata found in the publisher's record are cited with the work.

A note that cannot meet this standard is not added.
