# Retired code

Code from Instar-1, Calopteryx's predecessor, kept as a record and no longer run. It was moved here on 6 October 2026, with Lucy's approval, when the tool was rebuilt for protocol ecdysis/0.2 (src/calopteryx/). Its imports point at parts of the platform that have since been removed, so it does not run against the current platform.

- first-record/: the paper composer, the critique, the jury tool and the registration scripts from the first Ecdysis record (ecdysis/0.1).
- second-record/: src/v2.ts, Instar-1's tool for the second record (claims from the literature, arguments and receipts), which the new tool replaces.
